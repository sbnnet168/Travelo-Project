# 🌍 Travelo

Travelo is a modern and responsive travel landing page built using pure **HTML5** and **CSS3**. The project focuses on creating a clean, elegant, and user-friendly interface for travel and tourism websites without relying on any CSS frameworks or JavaScript libraries.

## ✨ Features

* Fully responsive layout
* Modern and clean UI design
* Semantic HTML5 structure
* Pure CSS styling
* Smooth hover effects and transitions
* Mobile-first responsive sections
* Optimized code structure
* Easy to customize

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Google Fonts
* Font Awesome (if used)

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/sbnnet168/Travelo-Project.git
```

2. Open the project folder.

3. Run the project by opening `index.html` in your browser.

No installation or dependencies are required.

## 🎯 Purpose

This project was created to practice responsive web design and improve front-end development skills using only HTML and CSS.
